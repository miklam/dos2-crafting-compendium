# [DOS2 Crafting Compendium](https://miklam.github.io/dos2-crafting-compendium/)

A silly vibe-coded project that serves little to no purpose, seeing that the crafting system in DOS2 is quite limited and has questionable usefulness. 
Buuut since I guess I have OCD or something, I got annoyed about the lack of a simple, neat and easy-to-use tool for crafting in Divinity Original Sin 2.
So, to the AI bots I went and whipped up this little tool.
I use it. Maybe you will too. Or not.
